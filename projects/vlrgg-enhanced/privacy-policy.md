## 1. Introduction

VLR.gg Enhanced is a Chrome extension that adds additional analysis and views to VLR.gg pages.
This Privacy Policy explains what information is processed, why it is processed, and how it is handled.

## 2. Information We Process

### 2.1 Information from supported pages

The extension runs only on:

- `https://vlr.gg/*`
- `https://www.vlr.gg/*`

On these pages, it reads page context needed to work (for example, public team, player, match, and event identifiers visible in the page URL or page structure).

### 2.2 Requests to the extension API

To provide enhanced insights, the extension sends requests to:

- `https://vlrggapi-tau.vercel.app/*`

These requests may include public identifiers and filters needed to retrieve statistics and related data.

### 2.3 Optional feedback link

The extension includes an optional "Share Feedback" link that opens an external Google Form (`forms.gle`).
Submitting that form is voluntary and governed by Google's terms and privacy policies.

## 3. Information We Do Not Collect

VLR.gg Enhanced does not intentionally collect:

- account passwords or login credentials
- payment information
- personal messages or email content
- browsing activity outside supported VLR.gg domains

The extension is not designed for behavioral advertising and does not sell personal data.

## 4. Permissions and Their Purpose

- `storage`: Reserved for extension configuration and future user preferences.
- Host permissions for VLR.gg domains: Required to run the content script on supported pages.
- Host permission for `vlrggapi-tau.vercel.app`: Required to fetch enhanced statistics.

## 5. Data Sharing

Data required for extension features is transmitted to the extension API endpoint above.
No additional third-party data brokers are used by the extension itself.

## 6. Data Retention

The extension does not maintain a remote user profile or a remote browsing-history database.
Any local extension settings, if present, remain in the browser until the user clears them or uninstalls the extension.

## 7. Security

The extension uses HTTPS for production API communication.
No method of internet transmission or local software storage is 100% secure, but reasonable technical measures are used to reduce risk.

## 8. Children's Privacy

The extension is not directed to children under 13 and is not intended to knowingly collect personal information from children.

## 9. Changes to This Policy

This policy may be updated from time to time.
When material updates are made, the "Last updated" date will be revised.

## 10. Contact

For privacy questions or requests, use the contact information provided in the Chrome Web Store listing for VLR.gg Enhanced.
