# Project Legal Pages

Use this repository to host terms and privacy pages for each project.

## Example project

- [Example Extension - Privacy Policy](/example-extension/privacy-policy)
- [Example Extension - Terms](/example-extension/terms)

## How to add a new project

1. Create `projects/<project-slug>/privacy-policy.md`
2. Create `projects/<project-slug>/terms.md`
3. Copy the template below and update:
   - `title`
   - `permalink`
   - markdown content

Template:

```md
---
title: Privacy Policy
permalink: /<project-slug>/privacy-policy
---

# Privacy Policy
Your content here.
```
